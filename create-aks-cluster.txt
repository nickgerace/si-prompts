Using this quickstart guide - https://github.com/Azure/azure-quickstart-templates/tree/master/quickstarts/microsoft.kubernetes/aks set up Microsoft Azure components accordingly to do what the guide does. Use the "aks" change set. Do not use any other change set. Use the existing Location, Credential, Subscription and Resource Group components. Use a supported version and include use the major and minor semantic version numbers (e.g. "1.32") - https://learn.microsoft.com/en-us/azure/aks/supported-kubernetes-versions. Give the cluster the name "demo-cluster".
